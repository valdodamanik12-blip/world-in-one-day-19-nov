news of Thursday 19 November 2026. All six stories were researched on 20 November
2026 (WIB) and cross-checked against at least two independent sources each.

invented, and no figure is carried from an earlier edition.

## Build notes

- `page.html` is a hand-written newspaper front page; every illustration is
  inline vector SVG drawn in the code (skyline and flags, scales of justice,
  tower, stock chart, cyclone spiral, aid score bar). No stock photos, no
  AI-generated imagery.
- `render.mjs` renders `page.html` to `entry.png` with the Playwright
  chromium-headless-shell binary (not /opt/meta-chromium).
- `main.ts` (Node 22, standard library only) copies `entry.png` to
  `$MAKEFUN_OUTPUT_DIR` (or `/output`).
- Verification: `entry.png` is 1024×1024, 232,574 bytes (under the 1 MiB
  limit), valid PNG signature. Rendered twice → byte-identical
  (sha256 a2f533c7513dcc3a35f96309642373ea7dae78d85051eba4b1df7704086b4c0c).
  `main.ts` run twice with `MAKEFUN_OUTPUT_DIR` → byte-identical output.
  Visual check: all headlines spelled correctly, dates and figures match the
  sources above, no clipped or overlapping text (one caption overlap found
  in review was fixed and re-rendered).
